# AVP downloads

Installers for the Audio Vision Productions editing tools, too big for the site repo (GitHub refuses files
over 100 MB there). Each tool has one release, tagged with the tool's name, and its files carry no version,
so a download link never changes: an update replaces the files in place.

| Tool | Release | Files |
|---|---|---|
| Paperboy | `paperboy` | `Paperboy-Setup.exe` (Windows, signed), `Paperboy.dmg` (Mac, Apple silicon, notarized) |

The pages that link here are on https://audiovisionproductions.ca. Each tool's own repo has the script that
uploads its files (Paperboy: `tools/release_downloads.js`).
